Overview

In this assignment we implement a simple rasterizer for a simplified version of SVG files. Starting with drawing single-color triangles, we then use a small grid of blocks to speed up rasterization. Next we add supersampling to make the triangle edges smoother. And also implement under block sampling. Another interesting part is transforms: we use homogeneous coordinates for translation, scaling, and rotation, and add keyboard controls to rotate the whole view. We also use barycentric coordinates to interpolate colors and texture coordinates across triangles. In the end we implement nearest and bilinear texture sampling, then add mipmap level sampling to reduce aliasing. Together these parts give us a vector graphics renderer that can display simplified SVG files.
